ICA HOMEPAGE UPDATE
===================

This package contains four replacement files:

1. index.html
2. css/styles.css
3. js/main.js
4. assets/images/nathan-ica-seated.png

HOW TO INSTALL
--------------

Copy these files into your existing ICA---Website project and keep the
same folder structure. Allow the new files to replace files with the
same names.

Do not delete:
- free-training.html
- explore-ica.html
- Resources/
- your existing PDFs or other assets

WORKING LINKS
-------------

The homepage is connected to:
- explore-ica.html
- explore-ica.html#about
- explore-ica.html#ai-coaches
- free-training.html
- ICA Pro Hub
- Free WhatsApp Community
- NOWOS
- ICA YouTube channel

YOUTUBE ERROR 153
-----------------

When index.html is opened directly from a computer, the video changes
to a clean clickable poster because local file pages can trigger
YouTube Error 153.

After the files are uploaded to GitHub Pages, the embedded video will
be used normally.

This package updates the homepage design while preserving the existing
shared CSS rules needed by free-training.html and explore-ica.html.
